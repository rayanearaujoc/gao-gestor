# GAO Gestor

Protótipo da plataforma do gestor da GAO Logística (HTML, CSS e JavaScript puros), feito com o GAO Kit (classes `gk-`).

Para ver: abra `index.html` no navegador. Páginas: Operação, Comandas, Clientes, Rotas, Motoristas, Veículos, Viagens, Comprovantes, Multas, Configurações e Suporte.
